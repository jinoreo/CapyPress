# Image Processing Tool

一个优雅的在线图片处理工具，具有现代化的设计风格和流畅的用户体验。

## 🌟 功能特点

- 📤 拖拽上传图片
- 🖼️ 实时图片预览
- 🎨 图片质量调节
- ⬇️ 一键下载处理后的图片
- 💫 流畅的动画效果
- 📱 响应式设计

## 🚀 使用方法

1. 将图片拖拽到上传区域或点击上传区域选择图片
2. 在预览区查看原图和处理效果
3. 使用质量控制滑块调整图片质量
4. 点击下载按钮保存处理后的图片

## 🛠️ 技术栈
